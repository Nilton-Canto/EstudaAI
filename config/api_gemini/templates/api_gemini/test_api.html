🚀 Teste da API EstudaAI

Interface para testar os endpoints da API Gemini

⚠️ Chave da API não configurada

Para usar a API do Gemini, você precisa configurar sua chave de API.

Passo 1: Obtenha sua chave em:
🔗 https://aistudio.google.com/app/apikey
Passo 2: Edite o arquivo config/.env
Substitua SUA_CHAVE_AQUI pela chave que você copiou
Passo 3: Reinicie o servidor Django
CTRL+C e depois python manage.py runserver
